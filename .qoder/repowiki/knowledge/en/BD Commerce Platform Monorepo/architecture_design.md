The workspace root is the orchestrator: `package.json` declares NPM workspaces under `apps/*` (web, api, medusa) and exposes unified scripts (`dev:web`, `dev:api`, `dev:medusa`, `build:*`, `prisma:*`, `docker:*`) that delegate to each child via `--workspace=`. `docker-compose.yml` provisions the shared runtime — PostgreSQL 16, Redis 7, and Meilisearch v1.11 on a common `bd_commerce_network` with healthchecks and named volumes — which all three apps connect to at runtime. The data plane flows from the web frontend through the Express API (Prisma-managed) into Medusa's commerce modules; the docs directory holds the authoritative PRD, DFD, database schema, and cross-audit artifacts that bind the three services' contracts together.
