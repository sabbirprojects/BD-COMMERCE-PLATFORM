Requires Node >= 22 and npm 10.9.8 (enforced via `engines` / `packageManager`). Environment variables are loaded from both the repo root and the app directory via `loadEnv` in `medusa-config.ts`; `DATABASE_URL` and `REDIS_URL` are required at runtime. Run with `npm run dev` (port 9000), `npm run build`, `npm run migrate` for DB migrations, and three Jest targets gated by `TEST_TYPE`: `test:integration:http`, `test:integration:modules`, `test:unit`.
