Run development with `npm run dev` (tsx watch), build with `npm run build`, start with `npm start`. Database setup requires running `npm run prisma:generate` followed by `npm run prisma:migrate` or `npm run prisma:push`; interactive DB browser available via `npm run prisma:studio`. The server expects a `.env` file at the repository root (loaded explicitly via `path.resolve(__dirname, '../../../.env')`).
