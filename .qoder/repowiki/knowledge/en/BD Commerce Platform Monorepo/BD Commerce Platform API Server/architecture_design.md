Single-file Express application entry point (`src/main.ts`) bootstraps the server: loads `.env` from the repo root, enables CORS and JSON parsing, registers a `/health` endpoint that probes the database via Prisma, and exposes `/api/v1` as the versioned API root. Database connectivity is centralized in `src/lib/prisma.ts`, which exports a singleton `PrismaClient` instance guarded by a `globalThis` cache to avoid connection leaks during hot reloads; logging is tuned per environment (query/error/warn in development, error-only in production). The app depends on external services wired through env vars — PostgreSQL/MySQL via Prisma, Redis via `ioredis`, and Meilisearch via `meilisearch` — though route handlers for categories/products/orders are not yet implemented. Build output goes to `dist/` with `tsc`, while development uses `tsx watch` for live reloading.
