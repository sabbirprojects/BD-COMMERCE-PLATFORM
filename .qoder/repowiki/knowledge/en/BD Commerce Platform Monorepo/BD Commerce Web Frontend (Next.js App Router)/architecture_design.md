Single-page Next.js application under `apps/web/` using the App Router (`src/app/layout.tsx`, `src/app/page.tsx`). The root layout in `layout.tsx` provides global metadata and imports shared styles from `globals.css`; the single route `page.tsx` renders a static marketing/status page listing core infrastructure services (PostgreSQL, Redis, Meilisearch, Node API, Next.js) and architectural highlights. `next.config.mjs` enables React Strict Mode and whitelists all HTTPS remote image hosts. Styling is handled by Tailwind CSS 3.4 via `tailwind.config.ts` and PostCSS (`postcss.config.mjs`). There are no additional routes, components, or API handlers — this app is a thin presentation shell for the monorepo's service catalog.
